# Support

Start with the [README](README.md), [project overview](docs/project-overview.md),
and [validation guide](docs/validation.md).

For a reproducible bug, open an issue with the caller, Node.js version, DSH
version, reproduction steps, and a sanitized error summary. Do not attach
credentials, private paths, session transcripts, or raw bridge state.

For vulnerabilities, follow the instructions in [SECURITY.md](SECURITY.md).
Do not disclose exploit details or secrets in a public issue.
